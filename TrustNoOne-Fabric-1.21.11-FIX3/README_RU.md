# TrustNoOne (horror) — Fabric 1.21.11

Кооперативный хоррор-мод для Java Edition. Проект рассчитан на Java 21, Fabric Loader и Fabric API. Дополнительные игровые моды, Simple Voice Chat и внешние runtime-библиотеки не нужны; Fabric API обязателен. Сам мод не проверяет лицензионный ключ и не обращается к внешним сервисам; возможность запуска самой Minecraft в офлайне зависит от установленного лаунчера.

## Сборка через GitHub Actions

1. Распакуйте архив.
2. Создайте пустой репозиторий GitHub и загрузите **всё содержимое** этой папки в корень репозитория (папка `.github` тоже нужна).
3. Откройте **Actions**. Сборка запускается при push в `main`/`master`, на pull request либо вручную через **Build TrustNoOne (horror) → Run workflow**.
4. В завершившемся запуске откройте **Artifacts** и скачайте `TrustNoOne-Fabric-1.21.11`. В JAR входит сам мод, а не Minecraft/Fabric.
5. Установите Fabric Loader для Minecraft 1.21.11, добавьте Fabric API той же версии и положите JAR мода в `mods`. Для LAN мод должен присутствовать у хоста и подключающихся игроков.

## Механики

- Общие жизни хранятся в `PersistentState` мира и переживают перезапуск. При смерти игрока появляется тело, счётчик общих жизней уменьшается, второй игрок теряет 2 HP. При нуле игра переводит игроков в spectator и завершает раунд (файлы мира не удаляются автоматически).
- Чтобы воскресить партнёра, наведитесь на тело и **удерживайте ПКМ 2 секунды** в пределах 4 блоков. Прогресс сбрасывается, если отпустить кнопку, отвести взгляд или отойти. Воскрешение возвращает игрока с 2 HP.
- Двойник появляется случайно возле игроков, берёт UUID одного из игроков для получения клиентской текстуры скина, использует имя как основу внешности, подражает приседанию/бегу/прыжку, открывает двери/люки/калитки поблизости и иногда визуально держит еду. Пока игрок, который может его видеть, направлен на него, двойник замирает; если на него не смотрят, он ускоряется и охотится.
- Имена над игроками/двойниками скрываются scoreboard-team и client mixin.
- Ночью и в местах с малым уровнем света конфиг может накладывать Darkness и уменьшать дальность прорисовки. Ч/б фильтра нет. Если `showSunAndMoon=false`, скрывается весь слой неба (в том числе звёзды): Minecraft рисует его единым проходом.
- Убийства животных, жителей и железных големов игроками увеличивают сохранённый грех мира. Пороговые значения усиливают ближайших враждебных мобов, накладывают Unluck и изнашивают броню.
- При включённой опции у эндерменов есть небольшой дополнительный шанс дропа Ока Эндера.

## Конфиг

После первого запуска создаётся `config/trustnoone.json`. Если меняете настройки во время игры, перезапустите мир, чтобы гарантированно применить все параметры. Дополнительно смотрите комментарии и значения по умолчанию в `config/TrustNoOneConfig.java`.

## Технические заметки

- Общие жизни и грех хранятся в данных мира; конфигурация — в папке `config` конкретного запуска.
- «Завершить раунд» не удаляет мир с диска: автоматическое удаление сохранений было намеренно исключено, чтобы мод не мог необратимо потерять пользовательский мир.
- Исправления сделаны по логу GitHub Actions Build #2. Этот ZIP не прошёл локальную компиляцию, потому что Gradle и загрузка зависимостей недоступны в этой среде; реальную компиляцию должен подтвердить следующий запуск GitHub Actions. Если Actions сообщит ошибку компиляции или запуска, пришлите лог целиком — по нему можно исправить конкретные несовпадения API.

## Важно для GitHub Actions

В корне репозитория должны находиться `build.gradle`, `settings.gradle`, `gradle.properties` и папка `src`. Папка `.github/workflows/build.yml` также должна быть именно в корне репозитория, а не внутри дополнительной вложенной папки. Workflow умеет искать проект во вложенных папках, но сам workflow GitHub запускает только из корневой `.github/workflows`. Если проект загружен как папка `TrustNoOne-Fabric-1.21.11/`, замените корневой `.github/workflows/build.yml` версией из этого архива либо перенесите содержимое папки проекта в корень репозитория.
