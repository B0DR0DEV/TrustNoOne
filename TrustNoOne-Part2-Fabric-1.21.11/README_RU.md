# TrustNoOne (horror) — Part 2 — Fabric 1.21.11

Кооперативный психологический хоррор-мод для Minecraft Java Edition 1.21.11. Требуются Java 21, Fabric Loader и Fabric API. Другие игровые моды и Simple Voice Chat не нужны. Мод не удаляет сохранение мира при проигрыше раунда и не обращается к внешним сервисам.

## Сборка через GitHub Actions

1. Распакуйте архив.
2. Загрузите **содержимое папки проекта** в корень репозитория. В корне должны быть `build.gradle`, `settings.gradle`, `gradle.properties`, `src` и `.github/workflows/build.yml`.
3. Откройте **Actions → Build TrustNoOne (horror)** и нажмите **Run workflow**. Сборка также запускается при `push` в `main`/`master`.
4. После успешного запуска скачайте артефакт `TrustNoOne-Fabric-1.21.11`.
5. Установите Fabric Loader для Minecraft 1.21.11, Fabric API для той же версии и собранный JAR в `mods`. В LAN мод нужен хосту и каждому игроку.

## Что доработано в Part 2

- **Воскрешение:** увеличена зона попадания тела для прицела, ослаблен слишком строгий серверный угол взгляда, добавлены понятные сообщения о начале, прогрессе и причинах сброса. Нужно держать ПКМ на теле 2 секунды в пределах 4 блоков и не отводить взгляд. В кооперативе игрока воскресить должен напарник.
- **Одиночное тестирование:** `lives.singleplayerTestingMode=true` по умолчанию разрешает тестовый режим в одиночном мире: после смерти нажмите обычную кнопку Respawn, вернитесь к телу и удерживайте ПКМ. Это исключение только для мира с одним игроком; в мультиплеере самовоскрешение не разрешено. Для одиночного теста также включено более частое появление двойника.
- **Двойник:** в первые секунды вне поля зрения он копирует направление взгляда, горизонтальное движение, бег, приседание и прыжки скопированного игрока. Если на него смотрят — он замирает. Если его не замечают достаточно долго — прекращает имитацию, начинает преследовать игрока и постепенно ускоряется. Открывание дверей/люков/калиток оставлено; визуальное поедание теперь длится заметное время.
- **Конфиг в LAN:** при подключении сервер передаёт клиентам текущие настройки JSON. Поэтому клиентские визуальные настройки (скрытие ников, ограничение дальности видимости, слой неба) используют конфиг хоста, а не случайно отличающийся локальный файл.
- **Темнота:** параметр `intensity` управляет продолжительностью эффекта Darkness. Никакого чёрно-белого фильтра нет.
- **Тело:** хитбокс увеличен для удобного наведения; тело остаётся отдельной сущностью, которую можно выбрать прицелом.

## Механики из основного ТЗ

- Общие жизни сохраняются в данных мира; при смерти появляется тело, уменьшается общий счётчик и живой напарник теряет указанное число HP. При нуле раунд заканчивается переводом игроков в spectator. Файлы мира автоматически не удаляются.
- Ники игроков скрываются scoreboard-командой на сервере и клиентским mixin; подписи двойника также скрываются по конфигу.
- Ночь и пещеры затемняются эффектом Darkness и сокращением дальности видимости. `showSunAndMoon=false` скрывает слой отрисовки неба целиком, включая звёзды, потому что игра рисует его одним проходом.
- Убийства животных, жителей и железных големов увеличивают сохранённый грех. По порогам усиливаются ближайшие враждебные мобы, накладывается Unluck и постепенно изнашивается броня.
- Дополнительный редкий дроп Ока Эндера с эндермена включается/отключается в конфиге.

## Конфиг

После первого запуска создаётся `config/trustnoone.json`. Важные параметры:

- `lives.startingLives`, `partnerHealthLoss`, `reviveHealth`, `reviveTicks`, `singleplayerTestingMode`, `reviveLookDot`;
- `imposter.enabled`, `spawnIntervalTicks`, `spawnChancePercent`, `minDistance`, `maxDistance`, `noticeDot`, `openDoors`, `copyCrouchingAndSprinting`, `copyJumping`, `despawnDistance`, `huntDelayTicks`, `fakeEatDurationTicks`;
- `names.hidePlayerNames`, `hideImposterNames`;
- `darkness.enabled`, `darkenNights`, `darkenCaves`, `lightThreshold`, `intensity`, `visibilityRadiusChunks`, `showSunAndMoon`;
- `sins.enabled`, пороги усиления мобов, Unluck и износа брони;
- `eyeOfEnder.enabled`, `endermanDropChance`.

Для проверки двойника в одиночном мире стой на поверхности в обычной или более высокой сложности и не отключай `imposter.enabled`. В тестовом режиме он проверяет появление чаще, но спавн всё равно зависит от наличия подходящего места и случайного броска. Для проверки в LAN нужен второй игрок.

## Сборка и ограничения проверки

Это исходный проект версии `0.3.0`. В этой среде не удалось запустить Gradle, поскольку нет установленного дистрибутива и сетевой загрузки зависимостей. Поэтому **перед использованием Part 2 обязательно запустите GitHub Actions**. Если компиляция завершится ошибкой, пришлите лог начиная с первой строки `error:`; не удаляйте и не переименовывайте файлы по отдельности.
