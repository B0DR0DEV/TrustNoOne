# TrustNoOne (horror) — Part 5 — Fabric 1.21.11

Кооперативный психологический хоррор-мод для Minecraft Java Edition 1.21.11. Требуются Java 21, Fabric Loader и Fabric API. Другие игровые моды и Simple Voice Chat не нужны. Мод не удаляет сохранение мира при проигрыше раунда и не обращается к внешним сервисам.

## Новое в Part 5

- **Наблюдатель:** редкий силуэт, выглядящий как один из игроков, появляется на расстоянии в темноте. Он неподвижен, не атакует и исчезает после того, как на него несколько мгновений смотрят.
- **Шаги за спиной:** во время движения игрока в ночи или тёмной пещере могут прозвучать дополнительные шаги неподалёку и за препятствием. Звуки прекращаются, когда игрок останавливается.
- **Кто-то приходил домой:** хоррор-событие срабатывает ночью рядом с кроватью. Может открыться ближайшая закрытая дверь, раздаётся звук двери, а в чате появляются сообщения неизвестного.
- **Фальшивые сообщения от имени друга:** в чате появляется тревожная фраза с именем одного из реальных игроков, затем неизвестный опровергает сообщение, а имя пишет, что ничего не отправляло. Это постановочное игровое событие, а не настоящее сообщение игрока.
- **Предвестия Бога Грехов:** первые грехи вызывают всё более заметные предупреждения — личные сообщения, дальние косметические молнии и красные фразы. После четвёртого греха на короткое время вдали появляется неподвижный силуэт Визера. Пятый грех по-прежнему призывает настоящего босса.

## Сохранённые механики

- **Бог Грехов:** после пятого греха появляется усиленный Визер со стандартной полосой здоровья босса. Каждый следующий грех усиливает его в пределах настроенного максимума. Если убежать слишком далеко, он возвращается с молнией, пишет «ХОТЕЛИ УБЕЖАТЬ ОТ ГРЕХОВ?!» и наносит дополнительный урон.
- **Мягкая темнота без мерцания:** ночью экран затемняется слегка, а в глубоких пещерах — немного сильнее. Пульсирующий эффект Darkness не используется.
- **Ночные охотники:** усиленные зомби/кадавры преследуют игроков в ночной темноте.
- **Мимик:** копирует внешний вид и движения игрока, замирает под взглядом и начинает охоту, если его долго не замечают.
- **Общие жизни и тела:** смерти уменьшают общий запас жизней, оставляют тело, а игрока можно воскресить удерживанием ПКМ.
- **Система грехов:** убийства животных, жителей и железных големов повышают грех мира и усиливают угрозы.
- **Мистический чат, фальшивый вход и случайные молнии:** сохранены события из прошлых версий.
- **Око Эндера:** доступен небольшой альтернативный шанс выпадения с эндермена.

## Сборка через GitHub Actions

1. Распакуйте архив.
2. Загрузите **содержимое папки проекта** в корень репозитория. В корне должны быть `build.gradle`, `settings.gradle`, `gradle.properties`, `src` и `.github/workflows/build.yml`.
3. Откройте **Actions → Build TrustNoOne (horror)** и нажмите **Run workflow**. Сборка также запускается при `push` в `main`/`master`.
4. После успешного запуска скачайте артефакт `TrustNoOne-Fabric-1.21.11`.
5. Установите Fabric Loader для Minecraft 1.21.11, Fabric API для той же версии и собранный JAR в `mods`. Для игры в LAN мод нужен хосту и каждому игроку.

## Конфигурация

После первого запуска создаётся `config/trustnoone.json`. Новые параметры Part 5:

- `observer.enabled`, `intervalTicks`, `chancePercent`, `minDistance`, `maxDistance`;
- `mimicFootsteps.enabled`, `checkIntervalTicks`, `chancePercent`, `minSteps`, `maxSteps`;
- `homeHaunting.enabled`, `intervalTicks`, `chancePercent`, `radius`, `openNearbyDoor`;
- `fakeFriendMessages.enabled`, `intervalTicks`, `chancePercent`;
- `godPremonitions.enabled`, `omenDurationTicks`.

Существующие параметры жизней, Мимика, затемнения, ночных охотников, грехов, Бога Грехов и чата оставлены. В частности, `darkness.nightOverlayAlpha=20`, `darkness.caveOverlayAlpha=36`, `darkness.visibilityRadiusChunks=10` оставляют мягкую темноту без пульсации.

## Проверка сборки

Архив содержит исходный проект версии `0.6.0`. В этой среде отсутствует установленный Gradle, а загрузить дистрибутив и зависимости из сети не удалось. Поэтому **перед заменой рабочего JAR обязательно запустите GitHub Actions**. Если компиляция завершится ошибкой, пришлите лог начиная с первой строки `error:`; существующие файлы по отдельности не переименовывайте.
